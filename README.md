**RodSense** — современная система родительского контроля и баланса экранного времени для персональных компьютеров. Помогает семьям договариваться об играх и учёбе без ссор и стресса.

Этот репозиторий является официальным центром дистрибуции десктопного приложения RodSense для Windows и macOS.

## ✨ Возможности системы

- ⏱️ **Честный баланс экранного времени**: суточные лимиты, умные перерывы и звуковые предупреждения перед завершением игры.
- 👥 **Очередь игроков**: автоматическая передача хода между детьми по таймеру с защитой PIN-кодом.
- 🌙 **Защита сна**: блокировка компьютера в часы ночного отдыха и режим тишины.
- 🎙️ **Центр звуков**: приятные темы звукового оформления и возможность записи голоса родителя.
- 🛡️ **Защита от обхода**: защита системных часов от перевода даты, контроль процессов и автозапуск.

---

## 💻 Системные требования

- **Windows**: Windows 10 (версия 1903+) или Windows 11 (64-bit).
- **macOS**: macOS 12 (Monterey) и новее (Apple Silicon M1/M2/M3/M4).
